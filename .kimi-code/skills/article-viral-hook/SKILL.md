# Article Viral Hook × AA/AG × 痛点图谱 × 爆款标题

将长文章转化为高传播短帖 + 爆款标题候选，四步工作流：
**痛点匹配 → 爆点筛选 → AA/AG 帖文生成 + 标题/标签生成 → content-to-human-script 去 AI 味**

## 工作流程

```
用户提供文章
    ↓
[Step 1] 读文章 + 痛点匹配
    ↓
[Step 2] 筛爆点（五维标准 × 痛点匹配度）
    ↓
[Step 3] AA/AG 两段式写帖 + 生成爆款标题/标签
    ↓
[Step 4] 调用 content-to-human-script 去 AI 味
    ↓
输出 2-3 篇简短、自然、高传播的短帖 + 爆款标题候选 + 推荐标签
```

## Step 2：筛爆点（五维标准 × 痛点匹配度）

### 五维爆点标准

| 维度 | 判断标准 | 传播心理 |
|------|---------|---------|
| **反直觉** | 与常识相反，读者第一反应是"不可能吧" | 认知冲突驱动点击 |
| **情绪共鸣** | 戳中普遍存在的焦虑、委屈、渴望 | 情绪需要出口 |
| **身份认同** | 让某个群体觉得"这就是我" | 自我表达需求 |
| **实用利益** | 读完能省时间/省钱/避坑/提高效率 | 功利性收藏转发 |
| **争议空间** | 存在合理对立面，评论区能吵起来 | 讨论欲驱动传播 |

### 综合评分规则

- 同时命中 **高概率痛点（>60%）+ 多个爆点维度** → 优先选用
- 单一维度极强（如极强的反直觉数据）→ 第二优先
- 匹配度低但传播性极强 → 可作为辅助帖

## Step 3：AA/AG 两段式写帖 + 爆款标题/标签生成

### 3.1 AA/AG 两段式写帖（⚠️ 核心写作框架）

**必须使用两段式结构**，每篇帖文只保留两个部分：

```
A — Attention（钩子）     → 3秒抓眼球，1-2句话
A — Advantage（优势）     → 给出反常识新视角/核心观点，简短有力

或

A — Attention（钩子）     → 3秒抓眼球，1-2句话
G — Gamify/Amplify（放大）→ 给出一个具体行动 + CTA
```

#### 结构选择规则

| 结构 | 适用场景 | 帖文特点 |
|------|---------|---------|
| **AA** | 情绪共鸣、观点冲击、争议讨论 | 钩子 → 反常识观点/新视角，靠认知冲突传播 |
| **AG** | 实用攻略、行动引导、转化导向 | 钩子 → 具体可执行步骤 + CTA，靠实用价值传播 |

#### A 阶段：Attention（钩子）

从钩子类型库中选择，**优先选择与匹配痛点直接相关的钩子**：

| 钩子类型 | 适用场景 | 痛点锚定示例 |
|---------|---------|------------|
| **问题型** | 痛点共鸣 | "为什么过了35岁，简历就没人看了？"（锚定 #1） |
| **数字型** | 反直觉数据 | "80%的中年人正在经历……"（引用痛点数据） |
| **反常识型** | 打破迷思 | "你以为35岁是天花板？科学说正好相反" |
| **痛点共鸣型** | 情绪入口 | "如果你也因为年龄焦虑失眠……"（锚定 #2） |
| **时间框架型** | 转变叙事 | "30岁那年我以为人生结束了，40岁才发现……" |
| **负面经历型** | 信任建立 | "39岁之前，我投了200份简历没一个回复" |

#### A 阶段（第二段）：Advantage（新视角/优势）

**核心任务**：抛出文章核心观点或反常识结论，让读者感到"原来还能这么想"。

**必须包含**：
- 文章中的核心新观点/新概念（一句话）
- 证据支撑：金句、数据、案例、名言（至少 1 项）

**写作公式**：
```
[转折/点明] + [新视角一句话] + [证据/金句支撑]
```

#### G 阶段（第二段）：Gamify/Amplify（行动引导）

**核心任务**：给出一个今天就能做的具体动作 + 明确 CTA。

**必须包含**：
1. **1 个具体可执行步骤**（足够小，今天就能做）
2. **一个明确的 CTA**：
   - 互动型："评论区说说你的……"
   - 引流型："完整方法在原文里"
   - 行动型："今天就做这一件事"

**写作公式**：
```
[具体动作] + [为什么这个动作用] + [CTA]
```

#### 篇幅要求

- 每篇帖文控制在 **150-400 字**
- 段落不超过 4-5 段
- 避免长篇论述，保持"刷到即懂"

### 3.2 爆款标题/标签生成（⚠️ 新增模块）

基于 `toutiao-title-craft` 的标题设计方法论，为文章生成爆款标题候选和推荐标签。

#### 标题生成核心铁律

1. **前13字定生死** — 手机端标题只显示前13-16字，核心钩子必须前置
2. **一标题三技巧** — 爆款标题平均使用3.2种结构技巧组合
3. **数字是第一吸引力** — 46%的爆款标题包含具体数字
4. **情绪>信息** — 先调动情绪，再传递信息
5. **话说一半留一半** — 47.8%的爆款标题使用悬念机制
6. **痛点匹配优先** — 基于 Step 1 匹配的高概率痛点创作标题

#### 10 大标题公式

| # | 公式名 | 模板 | 适用场景 |
|---|-------|------|---------|
| 1 | 数字悬念利益 | `[数字]招[动作]，[利益结果]！[权威]` | 健康/职场/副业 |
| 2 | 反常识颠覆 | `[普遍认知]？[否定]，[反常识结论]` | 科普/历史/健康 |
| 3 | 揭秘真相 | `[揭秘][事件]，[不为人知]的[真相]` | 历史/军事/社会 |
| 4 | 故事数字反转 | `[年龄/身份]+[数字]，[事件]+[反转]` | 情感/家庭/故事 |
| 5 | 痛点利益 | `[痛点场景]，[利益承诺/解决方案]` | 健康/职场/育儿 |
| 6 | 冲突反转爽感 | `[压迫]，[反击]，[爽感结局]` | 职场/家庭冲突 |
| 7 | 设问引导 | `[为什么/如何][现象]？[悬念]` | 情感/育儿/科普 |
| 8 | 热点绑定 | `[热点事件]，[利益/悬念]` | 科技/财经/社会 |
| 9 | 权威揭秘 | `[身份/数据]，[揭秘]+[内容]` | 健康/职场/财经 |
| 10 | 极端情绪 | `[极端情绪/行为]，[反差结果]` | 情感冲突/正能量 |

#### 辅助技巧叠加

- +数字 → 增强可信度
- +悬念 → 用"它""这一步""这样"不透露答案
- +权威 → 老中医/10年HR/央行数据
- +热点 → 绑定DeepSeek/AI/最新政策
- +冲突 → 制造反差和矛盾
- +情感 → 扎心/崩溃/暖心

#### 标题输出要求

- 生成 **至少10个** 候选标题
- 每个标题标注使用的**痛点类型**、**公式编号**和**技巧标签**
- 字数控制在 **16-25字**（最佳区间）
- 前13字必须包含至少1个钩子（数字/悬念/冲突/利益）

#### 推荐标签

- 最多推荐 **5个标签**，每个标签 **2-8字** 最佳
- 标签分类：
  - 核心标签 1-2个：精准概括文章主题
  - 扩展标签 1-2个：相关领域延伸
  - 热门标签 1个：蹭热度增加曝光

### 3.3 平台适配

| 平台 | 字数 | 风格特点 |
|------|------|---------|
| **微头条** | 200-500字 | 可加话题标签，段落感强 |
| **微博** | 150-400字 | 精炼有力，善用超话，互动感强 |
| **小红书** | 150-400字 | 情绪先行，emoji适度，生活场景感 |
| **知乎** | 200-500字 | 重数据和逻辑，专业但不学术 |
| **X/Twitter** | 100-300字 | 极简，可拆分 thread |

## Step 5：调用 content-to-human-script 去 AI 味（⚠️ 必须执行）

**生成原始帖文后，必须调用 `content-to-human-script` 对帖文进行去 AI 化处理。**

### 调用方式

1. 将原始帖文保存为临时 Markdown 文件：
   - 路径：`{源文件目录}/.article-viral-hook-temp.md`
2. 调用技能：
   - `/content-to-human-script {源文件目录}/.article-viral-hook-temp.md`
   - 或直接使用 `Skill` 工具调用 `content-to-human-script`，参数为临时文件路径
3. 将 `content-to-human-script` 输出的人味文案作为最终帖文正文
4. 删除临时文件（可选，保持目录整洁）

### 去 AI 味后的要求

- 保留 AA/AG 结构和核心观点
- 保留痛点锚定和 CTA
- 语气像真人随手写的，不是机器生成
- 长短句交错，避免 AI 高频词和套路句式
- 去掉过度工整、过度对称、过度总结的表达
