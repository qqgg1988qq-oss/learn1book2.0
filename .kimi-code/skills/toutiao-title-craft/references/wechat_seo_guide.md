## 一、搜一搜排序机制

### 1.1 官方五因素【官方明确】

微信开放社区官方口径：搜一搜排序结果受以下五因素共同决定：

1. **运营时间**：账号注册与持续运营的时间长度
2. **运营频率**：更新是否规律、活跃
3. **历史违规行为**：违规记录越少排名越有利
4. **搜索用户的使用行为反馈**：点击、停留、完读、点赞、分享、收藏等
5. **搜索关键词的匹配程度**：用户搜索词与账号名称、标题、内容的匹配

官方同时说明：公众号召回以账号名称、内容和简介为主要依据；运营质量过低的账号可能无法被召回；排名由算法决定，暂不支持人工干预；不保证每篇文章都被收录。

### 1.2 PeopleRank：以"人"为节点的排序引擎

- 区别于百度的 PageRank（网页链接投票），搜一搜以"人"为节点，用户关注、阅读、点赞、在看、分享、收藏等行为构成排序信号。
- 权重顺序（从业者经验）：**内容优质 > 用户行为 > 账号权威**。
- 账号权重是"门槛"，互动数据是"加速器"，内容质量是"根基"。

### 1.3 千人千面

- 已关注的公众号、最近读过的文章会优先展示并打标。
- 文章被好友/群友阅读、点赞、收藏、分享后，在你的搜索结果中排名显著靠前。
- 实操含义：发布后的社群、朋友圈、好友分发不仅是推广，也是排序信号。

### 1.4 趋势：从关键词匹配到语义理解

- 2025 年起搜一搜灰度测试 AI 搜索并接入 DeepSeek-R1。
- 排序逻辑正从关键词匹配转向语义理解与意图识别。
- 用户行为信号实时化，时效性权重上升。
- 未来"把问题回答好"比"把关键词放对"更重要。

## 二、关键词挖掘（按可靠性排序）

### 2.1 搜一搜下拉框 + 相关搜索【官方功能】

- 在搜一搜输入核心词，记录下拉推荐词和结果页底部"相关搜索"。
- 这些是用户真实搜索句式，是选题与标题词库的第一手数据。
- 定期记录，跟踪季节性变化（开学季、年末书单等）。

### 2.2 公众号后台"搜索关键词"数据【官方功能，需开通流量主】

- 在"内容分析"中查看用户通过哪些词搜索进入你的文章。
- 唯一"已验证能带来流量"的词库，可直接复用。
- 关注"零阅读文章"的搜索词，发现被忽略的潜在需求。

### 2.3 微信指数【官方免费小程序】

- 查看目标词 7/30/90 日热度曲线，支持多词对比和订阅推送。
- 注意：微信指数是微信生态综合热度，不等于纯搜索量；指数过低的词可拆解为更具体的长尾词再查。

### 2.4 第三方工具补充【从业者经验】

- 5118（长尾词拓展）、爱站网（竞争度分析）、百度指数/百度风云榜（站外热度参考）。

## 三、长尾关键词策略

### 3.1 关键词矩阵【从业者经验】

```
核心词 → 长尾词 → 场景词
人类简史 → 人类简史讲了什么 → 人类简史适合什么人读
```

### 3.2 长尾词公式【从业者经验】

- 核心词 + 疑问词（怎么/如何/值得吗/讲什么）
- 核心词 + 人群（新手/上班族/宝妈）
- 核心词 + 时间（2026、开学季、双11）

### 3.3 判断一个词值不值得做【从业者经验】

- 搜该词看结果页：前排若是发布好几个月的老文章，说明该词可做长期排名。
- 前排全是新文章，说明排名轮换快、难维持。

### 3.4 宽泛词 vs 长尾词

- 宽泛词竞争大、意图模糊。
- 精准长尾词（"年份 + 场景 + 避坑/实操"式）搜索量小但意图明确、竞争低，是新号突围的主战场。

## 四、标题写作规范

### 4.1 三大标题公式【从业者经验】

1. **数字 + 关键词 + 价值承诺**
   - 示例："7 个应届生面试技巧：从简历到沟通全攻略"

2. **人群 + 痛点 + 解决方案**
   - 示例："2 个月宝宝发烧怎么办？附 20 个退烧误区自查表（新手爸妈必存）"

3. **问句式标题（直接用用户搜索句式）**
   - 示例："如何提升搜一搜排名""苏菲的世界讲了什么"

### 4.2 长度与位置【从业者经验】

- 标题长度建议 **16–22 字**（另有"20 字左右"说法）。
- 订阅号信息流中，手机屏幕 **前 8–12 字** 决定用户能否看到关键信息。
- 核心关键词尽量落在标题前半段，但**语序自然永远优先于位置**。
- 一个标题自然融入 **1–2 个关键词** 即可，严禁罗列堆砌。

### 4.3 发布前检查【官方明确】

- 2025 年 4 月起，公众号文章发布后标题仅可修改 **3 个字**，每篇仅一次机会。
- 发布前必须：用微信指数验证关键词热度 → 用搜一搜验证竞争度 → 通读确认标题与正文一致。

## 五、关键词闭环【从业者经验，部分有官方指南背书】

除标题外，在以下位置自然复现核心关键词：

1. **摘要**：前 40–60 字内再次嵌入关键词。
2. **正文首段 100 字**：直接回答搜索问题。
3. **小标题**：每个小节尽量包含关键词或其变体。
4. **结尾**：总结处再次呼应。
5. **公众号名称 / 功能介绍**：自然融入 1–2 个核心词（同一关键词超过 2 次可能触发监测）。
6. **菜单栏名称**：高频点击菜单会出现在搜一搜结果中。
7. **合集标签**：增强主题相关性。

**注意**：正文关键词密度没有官方标准，流传说法互相矛盾（2%–5%、2%–3%、≤0.3% 等），只能作为"不要堆砌"的定性参考。

## 六、账号权重与互动数据

### 6.1 账号权重（决定你能不能进场）【从业者经验】

- 认证状态：企业/机构认证（蓝 V）> 个人认证 > 未认证
- 注册时间与历史沉淀：老号、无违规、内容沉淀多权重更高
- 原创标识：开通原创、原创文章占比高；基准线每周至少 3 篇原创、持续 3 个月以上
- 更新频率：长期不推送被视为"僵尸号"降权
- 违规记录/信用分：低质/营销过重内容会整体降权，连累历史优质文章（连坐效应）

### 6.2 互动数据（进场后排第几）【从业者经验】

参与维度：阅读量、完读率、点赞、在看、分享、收藏、评论。

权重序列：**转发 > 收藏 > 完整阅读 > 点赞 > 评论**。

- 发布后 **24–48 小时** 是关键窗口，通过社群、朋友圈、好友分发撬动早期互动。
- 文末设计互动引导，收藏和分享的引导优先于点赞。

## 七、避坑清单

### 7.1 五类标题党违规【官方明确】

微信公众平台 2024 年两次公告明确打击：

1. 混淆官方类：仿冒官方通知、公告格式
2. 煽动蛊惑类：制造恐慌或情绪
3. 生活养生夸大误导类
4. 公众人物负面误导类
5. 对抗审核类：空格、生僻字、火星文、特殊符号绕开审核

处罚梯度：删文 → 扣信用分 → 限制功能 → 永久封号。

### 7.2 关键词堆砌与恶意 SEO【官方明确 + 从业者经验】

- 占用通用或宽泛关键词、关键词堆砌、仿冒知名主体、标题与内容无关，均被官方列为恶意 SEO。
- 标题含 1–2 个核心词、位置靠前、语序自然，是唯一可持续的做法。
- 反例："面试技巧 + 应届生面试 + 面试沟通 + 简历技巧" 会被判恶意 SEO。

### 7.3 蹭热点边界

- 热点内容有 48–72 小时排名窗口期。
- 蹭热点只做信息增量，注明来源、时间、地点。
- 不硬蹭与账号定位无关的热词；不借热点做标题党。

### 7.4 其他高频红线

- 杜绝绝对化用语（"最全""第一""100%"）
- 杜绝煽动性表述（"彻底沸腾""看完即删"）
- 标题与正文必须一致
- 不频繁改名（每月超过 1 次，经验推测）
- 不刷量、不搬运洗稿、不大篇幅广告、不使用不符合跳转逻辑的链接

## 八、搜一搜 SEO vs 百度 SEO 本质差异

| 维度 | 百度 SEO | 微信搜一搜 SEO |
|------|---------|---------------|
| 核心逻辑 | 关键词匹配 + 网页权重（PageRank） | 相关性 + 账号权重 + 用户行为 + 社交关系链（PeopleRank） |
| 排序因素 | 外链、域名权重、关键词密度 | 运营时间、频率、违规、用户反馈、关键词匹配 |
| 个性化 | 较弱 | 千人千面 |
| 惩罚机制 | 降权、K 站 | 沙盒机制、封禁搜索能力、信用分连坐 |
| 旧套路有效性 | 堆砌关键词、伪原创曾长期有效 | 全面失效且触发处罚 |
| 流量形态 | 搜索流量为主 | 长尾资产，可持续数月到数年 |

## 九、一页纸行动清单

### 账号层

- [ ] 能认证尽认证
- [ ] 开通原创声明，原创文章占比持续拉高
- [ ] 固定更新节奏，避免断更超过 3 天
- [ ] 公众号名称、功能介绍自然融入 1–2 个核心关键词
- [ ] 菜单栏名称含核心关键词

### 每篇文章

- [ ] 搜一搜输入核心词，记录下拉联想词 + 相关搜索
- [ ] 微信指数验证目标词热度
- [ ] 后台"搜索关键词"数据复用已验证的词
- [ ] 搜目标词看结果页前排文章新旧，判断能否做长期排名
- [ ] 标题含 1–2 个核心关键词，尽量靠前但语序自然
- [ ] 标题长度 16–22 字，前 8–12 字包含关键信息
- [ ] 套用公式：数字+关键词+价值承诺 / 人群+痛点+解决方案 / 问句式
- [ ] 摘要、首段、小标题、结尾自然复现关键词
- [ ] 文末设计收藏/分享引导 + 评论区话题
- [ ] 发布后 24–48 小时通过社群/朋友圈撬动早期互动

### 风控

- [ ] 自查五类标题党红线
- [ ] 确认无关键词堆砌、题文不符、绝对化用语
- [ ] 监测后台"搜一搜"来源占比与关键词排名
- [ ] 连续多篇搜一搜来源为 0 时排查隐形限流
- [ ] 旧文在 3 字修改额度内融入新热搜词
