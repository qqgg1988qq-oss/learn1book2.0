# Toutiao Title Craft — 今日头条 & 微信公众号双平台标题生成器

> 核心能力：一套命令覆盖「今日头条推荐流爆款标题」与「微信公众号/搜一搜 SEO 标题」两个场景。先选平台，再按对应机制生成标题与标签。

## 双平台核心差异

| 维度 | 今日头条 | 微信公众号/搜一搜 |
|------|---------|------------------|
| **核心目标** | 推荐流高点击率 | 搜索排名 + 信息流点击率 |
| **排序逻辑** | 推荐算法 + 用户互动 | PeopleRank（人的投票）+ 账号权重 + 用户行为 + 关键词/语义匹配 |
| **标题第一原则** | 前13字必须留钩子 | 含1–2个真实搜索词，核心词尽量前置但语序自然 |
| **字数区间** | 16–25字 | 16–22字（经验值） |
| **关键词策略** | 热点词 + 痛点词 | 长尾搜索词 + 疑问词/人群/时间 |
| **修改限制** | 发布后可修改 | 2025年4月起每篇仅可改3个字 |
| **主要风险** | 标题党低推荐 | 关键词堆砌、占用通用词、题文不符会被降权/封禁搜索能力 |

## 核心铁律（通用）

1. **平台决定写法** — 先明确是头条推荐流还是公众号搜索流，再开始写标题
2. **前13字定生死** — 手机端标题只显示前13–16字，核心钩子/关键词必须前置
3. **痛点匹配优先** — 先生成文章-痛点匹配，再基于高匹配痛点创作标题
4. **情绪>信息**（头条） / **意图>堆砌**（公众号） — 头条先调动情绪，公众号先回答搜索意图
5. **数字是第一吸引力** — 有具体数字的标题点击率显著更高
6. **话说一半留一半** — 爆款标题普遍使用悬念机制
7. **标题只能改一次**（公众号） — 2025年4月起公众号标题发布后每篇仅可改3个字，发布前必须验证

## 模式二：微信公众号/搜一搜 SEO 标题优化

针对依赖微信生态搜索流量（搜一搜 + 公众号订阅/朋友圈二次传播）的文章，标题优化必须同时满足「搜索召回」与「点击转化」两个目标。

### 平台机制（执行前必读）

微信搜一搜排序由五个官方明确因素共同决定：运营时间、运营频率、历史违规行为、搜索用户的使用行为反馈、搜索关键词的匹配程度。

- **关键词匹配只是五分之一**：只优化标题、不经营内容和互动，天花板很低。
- **用户行为反馈才是核心变量**：点击、停留、完读、点赞、分享、收藏等信号直接参与排序。
- **PeopleRank 以"人"为节点**：区别于百度的 PageRank，搜一搜把关注、阅读、点赞、在看、分享、收藏等用户行为作为排序投票。
- **千人千面**：已关注账号、好友互动过的内容会优先展示并打标。发布后的社群/朋友圈分发不仅是推广，也是排序信号。
- **长尾搜索流量是最大价值**：订阅流量几小时就衰减，但含真实搜索词的文章可持续数月甚至数年带来稳定流量。
- **趋势：从关键词匹配到语义理解**：2025 年起搜一搜灰度测试 AI 搜索并接入 DeepSeek-R1，排序逻辑转向语义理解与意图识别。未来"把问题回答好"比"把关键词放对"更重要。

### Step W1：挖掘用户真实搜索词

按可靠性优先级使用以下数据源：

1. **搜一搜下拉框 + 相关搜索（官方功能）**
   - 在搜一搜输入核心词（如"读书笔记"），记录下拉推荐词和结果页底部"相关搜索"。
   - 这些是用户真实搜索句式，直接可作为标题关键词库。
   - 定期记录，跟踪季节性变化（开学季、年末书单等）。

2. **公众号后台"搜索关键词"数据（官方功能，需开通流量主）**
   - 在"内容分析"中查看用户通过哪些词搜索进入你的文章。
   - 这是唯一"已验证能带来流量"的词库，可直接复用。
   - 关注"零阅读文章"的搜索词，发现被忽略的潜在需求。

3. **微信指数（官方免费小程序）**
   - 查看目标词 7/30/90 日热度曲线，支持多词对比和订阅推送。
   - 注意：微信指数是微信生态综合热度，不等于纯搜索量；指数过低的词可拆解为更具体的长尾词再查。

4. **第三方工具补充（从业者经验）**
   - 5118（长尾词拓展）、爱站网（竞争度分析）、百度指数/百度风云榜（站外热度参考）。

**输出**：整理出 10–20 个与文章主题相关的候选搜索词，标注每个词的来源、热度、竞争度。

### Step W2：选择长尾关键词

#### 关键词矩阵

按"核心词 + 长尾词 + 场景词"三层展开：

- 核心词："人类简史"
- 长尾词："人类简史讲了什么"
- 场景词："人类简史适合什么人读""人类简史第三章解读"

#### 长尾词公式

```
核心词 + 疑问词（怎么/如何/值得吗/讲什么）
核心词 + 人群（新手/上班族/宝妈）
核心词 + 时间（2026、开学季、双11）
```

#### 判断一个词值不值得做

- 搜该词看结果页：前排若是发布好几个月的老文章，说明该词可做长期排名。
- 前排全是新文章，说明排名轮换快、难维持。

#### 宽泛词 vs 长尾词

- 宽泛词竞争大、意图模糊。
- 精准长尾词（"年份 + 场景 + 避坑/实操"式）搜索量小但意图明确、竞争低，是新号突围的主战场。

**输出**：从候选词中精选 3–5 个核心长尾关键词，作为标题创作主轴。

### Step W3：生成候选标题

#### 公众号搜一搜三大标题公式

1. **数字 + 关键词 + 价值承诺**
   - 示例："7 个应届生面试技巧：从简历到沟通全攻略"
   - 适用：方法论、清单、攻略类内容

2. **人群 + 痛点 + 解决方案**
   - 示例："2 个月宝宝发烧怎么办？附 20 个退烧误区自查表（新手爸妈必存）"
   - 适用：母婴、健康、职场、情感等强痛点内容

3. **问句式标题（直接用用户搜索句式）**
   - 示例："如何提升搜一搜排名""苏菲的世界讲了什么"
   - 适用：问答型、解惑型内容，直接匹配长尾搜索

#### 长度与位置

- **标题长度建议 16–22 字**（经验值）：保证搜一搜结果页完整展示，又容纳关键词 + 钩子。
- **订阅号信息流中，前 8–12 字决定用户能否看到关键信息**（实测经验）。
- **核心关键词尽量落在标题前半段，但语序自然永远优先于位置**。生硬前置会降低点击率，而点击率会通过用户行为反馈间接影响排名。
- 一个标题自然融入 1–2 个关键词即可，严禁罗列堆砌。

#### 输出要求

- 生成 **至少10个** 候选标题。
- 每个标题标注：
  - **匹配搜索词**：基于哪个长尾词创作
  - **标题公式**：数字+关键词+价值承诺 / 人群+痛点+解决方案 / 问句式
  - **预估搜索排名潜力**：高/中/低
  - **预估点击率**：高/中
- 字数控制在 **16–22字** 最佳，**12–28字** 可接受。

### Step W4：构建关键词闭环

标题只是搜索召回的入口，正文需要在以下位置自然复现核心关键词，形成闭环而非堆词：

1. **摘要**：前 40–60 字内再次嵌入关键词（经验推测）。
2. **正文首段 100 字**：回答搜索问题，自然出现关键词。
3. **小标题**：每个小节标题尽量包含关键词或其变体。
4. **结尾**：总结处再次呼应关键词。
5. **公众号名称 / 功能介绍**：自然融入 1–2 个核心词（简介中同一关键词出现超过 2 次可能触发监测）。
6. **菜单栏名称**：高频点击菜单会出现在搜一搜结果中（有官方指南背书）。
7. **合集标签**：将相关文章归入同一合集，增强主题相关性。

**注意**：正文关键词密度没有官方标准，流传说法互相矛盾（2%–5%、2%–3%、≤0.3% 等），只能作为"不要堆砌"的定性参考。自然出现 1–2 次即可。

### Step W5：账号权重与互动数据

#### 账号权重（决定你能不能进场）

- 认证状态：企业/机构认证（蓝 V）> 个人认证 > 未认证。
- 原创标识：开通原创功能、原创文章占比高，建议每周至少 3 篇原创、持续 3 个月以上（经验推测阈值）。
- 更新频率：长期不推送会被视为"僵尸号"降权；稳定更新（如每周 2–3 篇）是维持权重的基础。
- 违规记录：低质/营销过重内容会被整体降权，连累历史优质文章（连坐效应）。

#### 互动数据（进场后排第几）

参与排序的维度：阅读量、完读率、点赞、在看、分享、收藏、评论。

权重序列（从业者经验）：**转发 > 收藏 > 完整阅读 > 点赞 > 评论**。

- 发布后 24–48 小时是关键窗口，通过社群、朋友圈、好友分发撬动早期互动数据。
- 文末设计互动引导，收藏和分享的引导优先于点赞。

### Step W6：避坑与合规

#### 五类标题党违规（官方明确打击）

微信公众平台运营中心 2024 年两次公告明确打击：

1. 混淆官方类：仿冒官方通知、公告格式（如"紧急通知""权威发布"式包装）。
2. 煽动蛊惑类：使用煽动性、蛊惑性表述制造恐慌或情绪。
3. 生活养生夸大误导类。
4. 公众人物负面误导类。
5. 对抗审核类：用空格、生僻字、火星文、特殊符号绕开审核。

处罚梯度：删文 → 扣信用分 → 限制功能 → 永久封号。

#### 关键词堆砌与恶意 SEO

- 占用通用或宽泛关键词、关键词堆砌、仿冒知名主体、标题与内容无关，均被官方列为恶意 SEO。
- 标题含 1–2 个核心词、位置靠前、语序自然，是唯一可持续的做法。
- 反例："面试技巧 + 应届生面试 + 面试沟通 + 简历技巧" 会被判恶意 SEO。

#### 蹭热点边界

- 热点内容有 48–72 小时排名窗口期。
- 蹭热点只做信息增量，注明来源、时间、地点。
- 不硬蹭与账号定位无关的热词；不借热点做标题党。

#### 其他高频红线

- 杜绝绝对化用语（"最全""第一""100%"）。
- 杜绝煽动性表述（"彻底沸腾""看完即删"）。
- 标题与正文必须一致，题文不符带来的高跳出率会反噬排名。
- 不频繁改名（每月超过 1 次，经验推测）。
- 不刷量、不搬运洗稿、不大篇幅广告、不使用不符合跳转逻辑的链接。
