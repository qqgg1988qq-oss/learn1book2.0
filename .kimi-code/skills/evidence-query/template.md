# 论据查询模板

根据用户查询主题，从论据库中检索最相关的论据卡片，并按统一格式返回。

---

## 查询信息

- **查询主题**：
- **意图类型**：概念解释 / 数据支撑 / 案例引用 / 金句点缀 / 综合写作素材
- **期望数量**：默认 5 条，可扩展至 10 条
- **素材类型**（可选）：概念 / 数据 / 案例 / 金句 / 全部
- **主题领域**（可选，如 #主题/商业）：
- **应用场景**（可选）：开头吸引 / 核心论据 / 反面论证 / 结尾升华
- **最低质量分**（可选）：4 / 3 / 无
- **排序方式**（可选）：相关度 / 质量分 / 日期

## 输出要求

- 调用 `scripts/evidence_query.py` 获取 TOP-N 结果
- 优先展示标题、来源、主题、场景、质量分、核心内容和适用场景
- 对 quality < 3 的素材，提示用户谨慎使用
- 如需综合写作，可在结果后附一段「组合建议」
- 保留每条结果的文件路径，方便用户点击查看原文
