## 三级筛选清单

### 第一级：预筛选（排除）

- [ ] 不是纯粹事实陈述
- [ ] 不是边角信息
- [ ] 来源明确或可验证
- [ ] 不笼统、有具体细节
- [ ] 不过时（或已说明适用边界）
- [ ] 不是资料库已多次覆盖的常识

### 第二级：六维质量评估

| 维度 | 评分（1-5） | 理由 |
|------|------------|------|
| relevance 相关性 | | 与核心论点的关联程度 |
| reliability 可靠性 | | 来源权威性 |
| timeliness 时效性 | | 信息新鲜度 |
| sufficiency 充分性 | | 论据完整度 |
| diversity 多样性 | | 稀缺/独特程度 |
| verifiability 可验证性 | | 可追溯原始来源 |

**通过标准**：总分 ≥ 18，且 relevance ≥ 3、reliability ≥ 3。

## 输出要求

- 每个通过质量评估的论据生成一个独立的 .md 文件
- 单篇材料提取上限 3-5 条
- 文件名使用小写：concept-XXXX.md / data-XXXX.md / case-XXXX.md / quote-XXXX.md
- 编号连续，从资料库现有最大编号递增
- 同步更新 /.../参考资料/论据库/00-索引.md
- 新卡片必须包含 topic、scene、quality 及六维分项
