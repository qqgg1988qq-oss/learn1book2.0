# 论据收集器

> **用途**：把散落的阅读材料变成**高质量、可检索、可复用**的写作弹药库。
> **核心原则**：宁可少存一条，也不让低质量素材污染库。

---

## 一、使用流程

### 用户提供材料

可以直接提供：
- 文章链接
- 文件路径
- 粘贴的文本片段
- PDF / EPUB / Markdown 文件

### 触发方式

```
/evidence-collector /path/to/article.md
/evidence-collector "粘贴的文本内容"
/evidence-collector https://www.example.com/article
```

或自然语言：

```
帮我把这篇文章里的论据整理一下
提取这个概念案例
把这段内容存进论据库
```

---

## 二、工作流

### 步骤 1：读取材料

读取用户提供的文本内容，分析其主题、类型和核心论点。

### 步骤 2：三级筛选提取论据

不再广撒网，而是按**三级筛选**控制质量。

#### 第一级：预筛选（排除明显低质量内容）

首先排除以下类型：
- 纯粹的事实陈述，没有观点支撑价值
- 与核心主题无关的边角信息
- 来源不明或不可验证的数据
- 过于笼统、缺乏具体细节的概括
- 明显过时（超过3年）且未说明适用边界的信息
- 已被资料库多次覆盖的常识性内容

#### 第二级：六维质量评估

对保留的候选素材进行 1-5 分评分：

| 维度 | 权重 | 说明 |
|------|------|------|
| **relevance 相关性** | 25% | 与文章核心论点的关联程度，逻辑链清晰 |
| **reliability 可靠性** | 20% | 来源权威、可验证 |
| **timeliness 时效性** | 15% | 近1-2年优先，经典理论可放宽 |
| **sufficiency 充分性** | 20% | 包含背景、数据、因果链等完整信息 |
| **diversity 多样性** | 10% | 是否属于稀缺/独特的论据类型 |
| **verifiability 可验证性** | 10% | 有明确出处，可追溯原始来源 |

**通过标准**：总分 ≥ 18 分（平均分 ≥ 3），且 **relevance ≥ 3 且 reliability ≥ 3**。

**单篇提取上限**：3-5 条。宁缺毋滥。

#### 第三级：结构化输出

对通过评估的素材，按统一 YAML + Markdown 格式输出。

### 步骤 3：去重与合并

对每条新提取的论据，调用 `scripts/evidence_dedup.py` 与资料库中已有论据做相似度判断。

**相似度阈值**：

| 相似度 | 处理方式 |
|--------|---------|
| ≥ 0.80 | 视为重复，跳过不入库 |
| 0.50 - 0.80 | 视为相近观点，合并到已有条目 |
| < 0.50 | 作为新论据入库 |

**合并规则**：

- **概念**：保留最清晰的定义，将新来源追加到 `source` 字段（用 `; ` 分隔），补充新的原文摘录到「原文摘录」区。
- **数据**：保留更精确或更新的数据，旧数据移入「补充数据」小节。
- **案例**：如果人物/事件相同，合并细节；不同则作为新案例。
- **金句**：如果原话相同或高度相似，跳过；如果只是主题相似，作为新金句。

### 步骤 4：分配编号

编号规则：

- 概念：`CONCEPT-XXXX.md`
- 数据：`DATA-XXXX.md`
- 案例：`CASE-XXXX.md`
- 金句：`QUOTE-XXXX.md`

编号从 0001 开始，按资料库中现有最大编号递增。

### 步骤 5：保存文件

保存到对应分类目录：

```
/Users/chouchou/Documents/Obsidian Vault/九局下半怎么破局/参考资料/论据库/
├── 概念/
│   └── concept-XXXX.md
├── 数据/
│   └── data-XXXX.md
├── 案例/
│   └── case-XXXX.md
├── 金句/
│   └── quote-XXXX.md
├── MOC-*.md
├── 常用检索.md
└── 00-索引.md
```

### 步骤 6：更新索引

在 `00-索引.md` 中追加新增论据条目，按类型分组，并标注 topic、scene、quality。

## 三、三维标签体系

每条论据必须同时标注三个维度，但**单篇素材标签不超过 5 个**。

### 维度 1：素材类型（type + subtype）

保留原有四大类，并增加二级细分：

| 一级 type | subtype 细分 | 说明 |
|----------|-------------|------|
| 案例 | 企业案例 / 人物故事 / 历史事件 / 实验研究 / 政策实践 | 记录背景、冲突、行动、结果、启示 |
| 概念 | 理论模型 / 思维框架 / 学术概念 / 方法论 | 记录定义、核心要素、适用边界、经典出处 |
| 金句 | 名人名言 / 书籍摘录 / 演讲金句 / 影视台词 | 记录原文、出处、说话人、适用语境 |
| 数据 | 统计数据 / 调研报告 / 实验数据 / 趋势指标 | 记录数据值、来源机构、发布时间、样本范围 |

### 维度 2：主题领域（topic）

使用嵌套标签格式 `#主题/一级/二级`，最多 3 个：

```
#主题/商业/营销
#主题/商业/管理
#主题/商业/战略
#主题/科技/AI
#主题/科技/互联网
#主题/社会/就业
#主题/社会/教育
#主题/文化/历史
#主题/文化/哲学
#主题/心理/认知
#主题/心理/情绪
#主题/经济/宏观经济
#主题/经济/消费
```

### 维度 3：应用场景（scene）

使用嵌套标签格式 `#场景/xxx`，最多 2 个：

```
#场景/开头吸引     #  shocking数据、反直觉观点、悬念故事
#场景/核心论据     #  权威研究、典型案例、有力数据
#场景/反面论证     #  失败案例、反面教材、争议观点
#场景/结尾升华     #  金句点睛、call to action、展望
```

## 四、论据卡片格式

```markdown
---
# 基础信息
id: CONCEPT-0001
type: 概念
subtype: 思维框架
title: 复利效应
source: 《原子习惯》
author: 詹姆斯·克利尔
url: ""
file: ""
date: 2018-10-16
created: 2026-07-04
updated: 2026-07-04
status: active

# 三维标签
topic: [#主题/心理/习惯, #主题/商业/自我管理]
scene: [#场景/核心论据]
tags: [习惯, 复利, 自我管理, 长期主义]

# 六维质量评分（1-5）
quality: 4
relevance: 5
reliability: 5
timeliness: 4
sufficiency: 4
diversity: 3
verifiability: 5
quality_status: human-confirmed
---

## 核心内容

每天进步1%，一年后你会进步37倍；每天退步1%，一年后几乎归零。
用你自己的话重述：复利效应说明微小的持续行动会在长时间内产生巨大的累积结果，正向习惯像滚雪球，反向习惯像温水煮蛙。

## 原文摘录

> 你不会上升到目标的高度，你会跌落到系统的水平。

## 适用场景

- 论证"微小习惯的力量"
- 反驳"一夜暴富"的幻想
- 说明长期坚持的价值

## 使用提示

适合作为文章的中段论据，配合具体数据或案例使用。避免单独使用导致说教感。

## 边界与局限

复利效应强调长期趋势，不适合解释短期波动；对"每天进步1%"也不要机械理解为可量化比例。

## 关联论据

- [[DATA-0001 习惯养成的成功率]]
- [[CASE-0001 英国自行车队的1%改进]]
```

### Frontmatter 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| id | 是 | 唯一编号 |
| type | 是 | 案例/概念/金句/数据 |
| subtype | 是 | 二级细分 |
| title | 是 | 简短标题 |
| source | 是 | 来源名称 |
| author | 否 | 作者/机构 |
| topic | 是 | 主题领域嵌套标签（1-3个） |
| scene | 是 | 应用场景嵌套标签（1-2个） |
| tags | 否 | 关键词标签 |
| quality | 是 | 总分（1-5） |
| relevance/reliability/timeliness/sufficiency/diversity/verifiability | 是 | 六维分项 |
| quality_status | 是 | `human-confirmed` / `ai-estimated` |
| date | 否 | 素材原始日期 |
| created/updated/status | 是 | 管理字段 |
