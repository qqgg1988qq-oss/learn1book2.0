# Article to Visual Rich Post — 文章视觉化+图文排版一站式工作流

将任意文章自动完成 **视觉场景拆解 → 图文混排 HTML 生成**，最终输出两个文件：

1. `visual-scenes.json` — 静态视觉场景描述文件
2. `article.html` — 已排好版面的富文本 HTML

> **核心原则**：
> - `visual-scenes.json` 中的每个场景都必须被 HTML 使用
> - 场景占位符位置必须严格依照 JSON 设计时的段落对应关系
> - 任意两个场景占位符之间必须有文字段落隔开，禁止连续堆叠
> - 不区分公众号/头条号，只输出一个通用 HTML

---

## 输出文件

输出位置默认与源文件所在目录一致。若用户未指定输出目录，则两个文件直接保存到源文件同级目录下：

```
{source-file-dir}/
├── visual-scenes.json    # 视觉场景描述文件
└── article.html          # 排好版面的富文本 HTML
```

例如源文件路径为 `/path/to/article.md`，则输出为 `/path/to/visual-scenes.json` 和 `/path/to/article.html`。

### visual-scenes.json 格式

```json
{
  "meta": {
    "title": "视频/文章标题",
    "source": "源文件路径",
    "scene_count": 20,
    "style_summary": "画面风格概述",
    "global_style_prompt": "全局画面基调描述"
  },
  "prompts": [
    {
      "scene_id": 1,
      "title": "场景标题",
      "keywords": ["可选：用于匹配文章段落的关键词数组"],
      "prompt": "100-200字静态画面描述"
    }
  ]
}
```

### article.html 格式

- 使用 `<section>` 作为最外层容器
- 使用 `<p>`、`<h1>`、`<h2>`、`<blockquote>`、`<hr>` 等安全标签
- 所有 CSS 必须内联到 `style` 属性中
- 场景使用文字占位符：`[ scene_id:场景标题 ]`
- 占位符以居中段落形式插入，不嵌入 `<img>` 标签

## 工作流程

### 步骤 1：接收并分析文章

读取用户提供的文章/文案，分析其结构：

- 主标题、副标题、正文段落
- 引用块、重点文字、列表、分割线
- 开头钩子、主体章节、结尾引导
- 识别每个段落的内容类型（概念解释、故事叙述、历史回顾、引用展示、批判性分析等）

### 步骤 2：确认视觉风格

向用户展示可用的视觉风格预设，等待用户选择：

| 序号 | 风格名称 | 适用场景 |
|------|---------|---------|
| 1 | `lofi-chill-vector` | 现代数字插画、高饱和撞色、Lo-Fi Chill 氛围、哲学/文艺内容 |
| 2 | `mental-health-grain` | 心理健康、情绪状态、内心独白、Instagram/Pinterest 风格内容 |
| 3 | `bw-etching-dystopia` | 黑白点刻版画、蚀刻/交叉排线、中国当代现实社会景观、城市纪实感、高密度细节插画 |
| 4 | `minimal-morandi-reader` | 极简扁平插画、莫兰迪配色、大留白构图、无面部人物、包豪斯美学、低饱和度、孤独阅读氛围、数字插画 |

用户也可以提供自定义风格描述。

### 步骤 3：确认画面中是否包含文字

在确定视觉风格后，必须向用户确认画面是否需要文字元素：

| 选项 | 名称 | 说明 |
|------|------|------|
| A | `with-text` | 画面包含标题、标语、标牌、对话框等文字元素，文字作为画面构图的一部分 |
| B | `no-text` | 纯画面表达，画面中不出现任何文字、字母、数字、标语、标牌或装饰性字体，仅通过视觉符号传达内容 |

默认选项为 `with-text`。若用户选择 `no-text`，则 `global_style_prompt` 和每个场景的 `prompt` 都必须明确禁止任何文字元素。

### 步骤 4：生成 visual-scenes.json

基于文章结构、用户选择的视觉风格和文字选项：

- 将文章拆解为 **15-25 个场景**
- 每个场景覆盖一个完整的讲解单元
- 每个场景的 `title` 必须与文章中对应段落语义相关（`title` 仅用于内部索引和 HTML 占位符，不直接出现在画面中）
- `prompt` 严格遵循选定视觉风格的视觉特征
- **若用户选择 `no-text`**：`global_style_prompt` 必须追加“画面中不出现任何文字、字母、数字、标语、标牌或装饰性字体，仅通过视觉符号与构图传达内容”；每个场景的 `prompt` 也必须以“画面无任何文字”收尾，且描述中不出现任何引号、标牌、对话框、文字等元素
- 所有画面描述必须是静态的，禁止动画、运动、镜头、特效描述

### 步骤 5：确认排版风格

默认固定使用「现代简约」排版风格，不再提供其他风格选择。

### 步骤 6：生成 article.html

根据 `visual-scenes.json` 和现代简约排版风格生成 HTML：

1. **预处理原文**：移除口播/朗读类提示词，包括 `（停顿）`、`（停顿X秒）`、`（放慢语速）`、`（压低声音）`、`（提高语调）`、`（笑）` 等，只保留适合图文阅读的纯文本
2. 分析文章结构，应用现代简约排版样式
3. 找到每个场景标题对应的段落位置
4. 在对应段落后插入文字占位符 `[ scene_id:场景标题 ]`
5. 确保每个场景都被使用
6. 确保任意两个占位符之间至少间隔一个正文段落
7. 添加文件头注释

### 步骤 7：输出文件

将 `visual-scenes.json` 和 `article.html` 保存到源文件所在目录。若用户明确要求指定目录，可按用户要求保存到指定位置。

## 视觉风格预设

### `lofi-chill-vector` —— Lo-Fi Chill 撞色矢量插画风

- **氛围**：松弛、复古未来感、适合深夜阅读和哲学沉思的 Lo-Fi Chill 氛围
- **视觉倾向**：现代数字插画，平面矢量质感，深色清晰描边，色块分明无渐变，灰绿色调几何拼贴背景
- **典型配色**：珊瑚粉 `#FF6B6B`、深蓝紫 `#4A2C8A`、薄荷绿 `#4ECDC4`、米黄 `#FFE66D`
- **典型元素**：几何色块拼贴、复古磁带/黑胶/台灯等 Lo-Fi 小物件、扁平化人物、抽象符号与文字标牌

### `mental-health-grain` —— 心理健康颗粒感插画风

- **氛围**：温暖、情绪化、聚焦内心独白与心理健康
- **视觉倾向**：扁平化插画（Flat Illustration）风格，人物造型简洁圆润，无复杂细节；整体带有颗粒感/噪点纹理（Grain Texture），营造复古和温暖的手作感
- **色彩**
  - 背景为紫色渐变（深紫→浅紫粉），过渡柔和
  - 主色调：紫色系 + 黄色（标题"NOT"）+ 珊瑚橙红（"OVERTHINK"）
  - 人物使用冷蓝灰色调，与背景形成层次感
  - 阴影部分使用深紫色剪影，象征心理负担
- **排版风格**
  - 大字排版（Bold Typography），主标题占据大面积视觉空间
  - 混合字重：大号粗体主标题 + 小号细体辅助说明文字
  - 引号（" "）作为装饰性排版元素，强化引用感
  - 文字与插画元素穿插排布，形成图文融合的版式
- **插画元素**
  - 孤独蜷缩的人物坐姿，头部有混乱线团（象征过度思考）
  - 夸张的黑色阴影剪影，带有超现实/象征主义意味
  - 情感表达直接，主题聚焦心理健康、情绪状态和内心独白
- **整体定位**：常见于 Instagram/Pinterest 心理健康内容创作者的风格：竖版、颗粒感插画、大胆排版、情绪化配色，兼具设计感与传播性

---

### `bw-etching-dystopia` —— 黑白蚀刻现实主义/社会观察插画风

- **氛围**：冷峻、真实、压抑，带有强烈的社会观察与当代都市寓言气质，聚焦中国现实社会景观而非西方奇幻或科幻设定
- **视觉倾向**：黑白点刻版画（Stipple Engraving）与蚀刻版画（Etching）混合，辅以密集的交叉排线（Cross-Hatching）塑造明暗与体积；无彩色，仅靠纯黑、纯白与丰富的灰阶层次构成画面
- **典型配色**：纯黑 `#000000`、象牙白/纸本色 `#F5F0E8`、深灰 `#2A2A2A`、中灰 `#808080`，严禁使用任何彩色
- **典型元素**：中国当代城市与社会景观——地铁车厢与换乘通道、城市高架桥与立交桥、写字楼玻璃幕墙、办公室格子间、早高峰通勤人群、低头看手机的身影、便利店、空白霓虹灯管（仅有光管轮廓，无文字）、共享单车、外卖箱、高层住宅楼、塔吊、施工围挡、待开发荒地、城市公园、老旧小区、石板路等；避免西方哥特式教堂、飞扶壁、蒸汽朋克机械、中世纪骑士、维多利亚装饰等异域元素
- **插画元素**
  - 人物：普通城市通勤者、办公室职员、外卖员、建筑工人等，身形修长或疲惫，姿态僵硬，常以群体阵列出现，营造机械复制与个体消失的反乌托邦感；面部表情空洞或隐于阴影
  - 场景：地铁站、写字楼、高架桥下、便利店、深夜办公室、城市广场、待开发地块、老旧小区、公园石板路等现实空间
  - 建筑：现代高层住宅、玻璃幕墙写字楼、施工围挡、塔吊、环形高架桥、螺旋停车场
  - 光影：强烈的明暗对比，光源常为狭长窗户、地铁顶灯、路灯、屏幕冷光，投射出戏剧化的长影
- **排版风格**
  - 标题使用古典衬线体或现代无衬线体，字形锐利、带有雕刻感
  - 装饰性元素：城市地图线条、建筑图纸标注线、蚀刻版画常见的细线装饰框
  - 文字与画面通过高对比度黑白关系融为一体，类似社会纪实摄影与版画的结合
- **整体定位**：适合社会批判、现实寓言、技术反思、哲学思辨、内卷/焦虑/中年危机等需要强烈视觉冲击与现实共鸣的内容；画面应像是从一本当代社会观察笔记里撕下的蚀刻插图，每一帧都承载叙事重量

### `minimal-morandi-reader` —— 极简扁平莫兰迪阅读氛围插画风

- **氛围**：安静、孤独、克制、沉思，适合深夜独处阅读与内省的阅读氛围
- **视觉倾向**：极简扁平插画（Minimal Flat Illustration），包豪斯美学的几何秩序感，大留白构图，无面部人物，低饱和度数字插画
- **典型配色**（莫兰迪色系）
  - 灰粉 `#C9B8A8` / `#D4C4B5`
  - 雾蓝 `#A3B4C4`
  - 灰绿 `#9DAD9F`
  - 暖驼 `#B8A18A`
  - 米白 `#F5F1EA`
  - 炭灰 `#6B6B6B`
  - 整体禁止使用高饱和、荧光、强对比色彩
- **构图**
  - 大面积留白，主体仅占画面 30%-50%
  - 水平线与垂直线构成稳定网格，暗合包豪斯比例
  - 人物与家具、书籍、器物之间保持疏朗距离
- **人物**
  - 无面部特征，仅以轮廓、发色、衣褶暗示状态
  - 身形修长、姿态静止，常以侧影或背影出现
  - 人物与空间的关系比表情更重要
- **典型元素**
  - 单人沙发、落地灯、散落的书本与咖啡杯
  - 大窗户、窗帘一角、月光或阴天柔光
  - 简约书架、几何花瓶、孤独植物
  - 阅读中的无面部人物剪影
- **光影**
  - 柔和漫射光，无明暗强烈对比
  - 阴影使用同色系低透明度色块，边缘干净
- **文字元素（仅 `with-text` 时）**
  - 使用极细无衬线体或几何感衬线体
  - 文字小面积出现，像空间中的装饰画签
  - 引号、页码、短句作为构图中的几何色块
- **整体定位**：适合文学解读、散文、书评、独处思考、知识分享、治愈系内容；画面应像一本安静的书被翻开，人物存在于空间而非叙事中

## 排版风格预设

### 现代简约（默认唯一风格）

- 主文字：`#1a1a1a`
- 正文：`#3f3f3f`
- 强调色：`#2c5aa0`
- H1：22px，底部蓝色边框
- H2：18px，左侧蓝色边框
- 正文：15px，行高1.75

其他排版风格预设已全部移除，本 skill 仅保留并使用「现代简约」风格。

## 视觉场景 prompt 写作规范

### 默认风格要求

`prompt` 的具体写法由用户在步骤 2 中确认的视觉风格决定。所有 prompt 必须：

1. **静态描述**：禁止任何动画、运动、镜头、转场、特效描述
2. **100-200字**：包含背景、主体、构图、色彩、文字元素（`with-text` 时）或视觉符号（`no-text` 时）
3. **风格与文字一致**：严格遵循选定风格的视觉特征，并遵守用户选择的文字选项
   - 若选择 `lofi-chill-vector`：使用高饱和撞色、几何色块拼贴、Lo-Fi 小物件、扁平化人物
   - 若选择 `mental-health-grain`：使用紫色渐变背景、颗粒感噪点纹理、圆润简洁人物、深紫色阴影剪影、大字排版、心理健康情绪主题
   - 若选择 `bw-etching-dystopia`：严格使用黑白两色与灰阶层次，以点刻、蚀刻、交叉排线塑造明暗；主体为中国当代现实社会景观——地铁、高架、写字楼、格子间、智能手机、便利店、外卖箱、共享单车、高层住宅、施工围挡等；人物为城市通勤者、办公室职员、外卖员等普通现代人，常以群体阵列或孤独个体出现；强调高密度细节、强烈明暗对比与现实社会的反乌托邦压迫感；禁止任何彩色、渐变、柔边或现代扁平化元素，避免西方哥特建筑、蒸汽朋克机械、中世纪骑士等异域元素
   - 若选择 `minimal-morandi-reader`：使用莫兰迪低饱和配色、极简扁平几何造型、大留白构图、无面部人物、包豪斯秩序感；人物身形修长静止，常以侧影或背影出现；场景为安静阅读空间（沙发、落地灯、书本、窗户）；光影柔和漫射，阴影为同色系干净色块；禁止高饱和、荧光、强对比色彩与复杂细节
4. **文字选项**：若用户选择 `with-text`，按各风格要求使用文字元素；若选择 `no-text`，则 `global_style_prompt` 与每个 `prompt` 都必须明确禁止文字，prompt 以“画面无任何文字”收尾

### 禁止出现的描述

- **动画类**：动画、动态、运动、移动、滑动、旋转、缩放、推近、拉远、淡入、淡出、闪烁、呼吸、抖动、粒子、消散、汇聚、爆裂、故障、glitch、扫描线、光流、缓缓、逐渐、慢慢、快速、突然
- **镜头类**：镜头、机位、视角、跟随、穿越、穿过、环绕、俯视、仰视、特写、全景、近景、远景、摇镜、移轴、Ken Burns
- **时间类**：然后、接着、之后、随即、约 X 秒后、X 秒后
- **特效类**：特效、光效、粒子效果、波纹、涟漪、3D 旋转、发光脉动

## HTML 构建规范

### 标签白名单

```
<section>, <p>, <span>, <strong>, <em>, <a>, <br>,
<h1>-<h6>, <ul>, <ol>, <li>, <blockquote>, <pre>, <code>, <hr>
```

### CSS 规则

- 仅使用行内 `style` 属性
- 不使用 class 或 id
- 颜色使用具体色值
- 使用系统字体栈

### 场景占位符插入规则（核心）

1. **必须每个场景都用上**：`visual-scenes.json` 中的每个 `scene_id` 都必须在 HTML 中生成对应的文字占位符
2. **依照 JSON 设计位置排版**：占位符必须插入到与场景标题语义对应的段落之后
3. **占位符不连续**：两个占位符之间必须至少间隔一个正文段落、小标题或分割线
4. **占位符格式**：统一使用 `[ scene_id:场景标题 ]`
5. **不使用 `<img>` 标签**：HTML 中不嵌入任何图片，只保留文字占位符，供用户后续手动替换或配图
6. **占位符样式**：使用简洁的文字段落占位，不使用背景框、边框、圆角等装饰性样式，避免视觉喧宾夺主

```html
<p style="text-align: center; color: #2c5aa0; margin: 24px 0;">
  [ 3:旧观点：文化是固定本质 ]
</p>
```

## 质量标准

- [ ] `visual-scenes.json` 包含 15-25 个场景
- [ ] 每个场景的 `prompt` 都是 100-200 字静态描述
- [ ] 所有场景的视觉风格统一
- [ ] 若用户选择 `no-text`，所有 `prompt` 均不包含文字、字母、数字、标语、标牌或装饰性字体
- [ ] HTML 严格使用行内 style，无外部 CSS 依赖
- [ ] 只使用白名单内的 HTML 标签
- [ ] HTML 中不包含任何 `<img>` 标签
- [ ] `visual-scenes.json` 中的每个场景都生成了对应的 `[ scene_id:场景标题 ]` 文字占位符
- [ ] 占位符位置与 JSON 设计时的段落位置一致
- [ ] 任意两个占位符之间至少有一个正文段落、小标题或分割线
- [ ] 不存在连续堆叠的占位符
- [ ] 已移除口播/朗读类提示词（停顿、放慢语速等）
- [ ] 配色方案符合 WCAG AA 对比度标准
