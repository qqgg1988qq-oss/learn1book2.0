# 文章观点提取器

> **用途**：你提供一篇文章，我帮你把作者在里面提出的所有观点逐条拎出来。

---

## 一、使用流程

### 你的输入

```
文章：______________（文件路径 / 链接 / 直接粘贴文本）
```

### 触发方式

直接输入：

```
/article-claims-extractor
```

或自然语言：

```
提取这篇文章的观点
帮我找出作者提出的所有论点
这篇文章的核心主张是什么
```

---

## 二、工作流

### 步骤 1：读取原文

- 如果用户提供的是**文件路径**，直接读取文件内容。
- 如果用户提供的是**网页链接**，请用户复制粘贴正文或提供截图/标题。
- 如果用户**直接粘贴文本**，将文本保存为临时文件 `{当前工作目录}/.article-claims-temp.md` 以便处理。

### 步骤 2：识别观点

在原文中系统寻找以下类型的观点：

- **核心论点**：作者最想证明或传达的中心主张
- **分论点**：支撑核心论点的二级观点
- **价值判断**：包含"应该""必须""更好""更糟"等规范性的主张
- **因果判断**："因为 A，所以 B""X 导致 Y"类的解释性观点
- **事实断言**：被作者当作论据使用的关键事实判断
- **隐含前提**：作者未明说但推理依赖的假设

识别时注意：
- 不要提取纯粹的描述、举例、引用、过渡句
- 不要提取显而易见的常识（除非作者对其有特别用法）
- 注意区分"作者的观点"和"作者引用的他人观点"

### 步骤 3：结构化输出

对每一条提取出的观点，输出：

- **观点编号**：1, 2, 3...
- **观点原文**：用中文概括或翻译原文中的该观点
- **观点类型**：核心论点 / 分论点 / 价值判断 / 因果判断 / 事实断言 / 隐含前提
- **支撑依据**：作者用了什么证据、例子、推理来支持这条观点（如有）
- **简要概括**：用一句话中文总结这条观点的要点

### 步骤 4：生成文件

将结果写入与源文件同目录的 `{源文件名}-claims.md`。

- 若源文件是 `article.md`，输出 `article-claims.md`
- 若源文件是 `{book-name}/chapter-01.md`，输出 `{book-name}/chapter-01-claims.md`
- 若只有临时文本无具体文件路径，输出到当前工作目录的 `article-claims.md`

### 步骤 5：清理临时文件

删除过程中创建的 `.article-claims-temp.md` 临时文件。

## 四、注意事项

- **输出语言**：无论原文是中文、英文还是其他语言，最终输出必须为中文。
- **观点忠实**：不要加入你自己的评价，只提炼作者说了什么、主张什么。
- **适度合并**：如果作者用多种方式反复表达同一个观点，合并为一条，标注"多次出现"。
- **不遗漏**：尽可能穷尽地提取，宁可多列也不要漏掉关键主张。
- **格式规范**：生成的 `-claims.md` 文件结构清晰，方便后续调用其他 skill 继续加工。
