# 头条评论生成器 — 使用示例

## 示例输入

```
话题：#现在高考和几十年前有啥不一样#
我的观点：现在的高考虽然制度更公平了，但孩子们的压力反而更大了，因为大家都太卷了
目标情绪：共鸣 + 轻微无奈
```

## 生成结果

### 痛点匹配

- 匹配痛点 1：教育内卷下的子女焦虑（匹配度：高）
- 匹配痛点 2：阶层跃迁通道收窄带来的无力感（匹配度：中）
- 情绪基调：共鸣、无奈、心疼

### 评论生成

#### 风格 A：情绪冲击型

> 我表弟今年高二，上周回家我看见他在吃抗焦虑的药。我问他怎么了，他说班里一半人都在吃。我听完一句话说不出来。我们那时候虽然也苦，但至少周末还能踢场球。现在的孩子是连喘息的时间都被"优化"掉了。

#### 风格 B：理性分析型

> 很多人只看录取率提高了，但忽略了一个数据：1997 年高考录取率 36%，2024 年超过 90%。表面看更容易上大学了，但 985/211 的录取率几乎没变。所以当"上大学"从稀缺变成标配，竞争就从"有没有"变成了"好不好"——这恰恰是焦虑的根源。

#### 风格 C：故事共鸣型

> 我爸是 1978 年参加高考的。他跟我说，那时候全村就他一个考生，复习材料是借来的半本书。考上那天，村里杀了头猪。去年我儿子高考，我们全家"静默陪考"，考完我问他怎么样，他说："爸，我觉得我再努力也拼不过那些人。"那一刻，我不知道该为时代进步高兴，还是为孩子难过。

#### 风格 D：反讽调侃型

> 现在的高考确实比以前公平多了——以前拼关系，现在拼补课费。以前差的是信息，现在差的是信息筛选能力。以前考不上怪自己，现在考不上怪"内卷"、怪"原生家庭"、怪"阶级固化"……总之，考试还是那个考试，锅已经不是原来的锅了。

#### 风格 E：短平快型

> 三十年前高考是独木桥，现在是高速公路——但所有人都在高速公路上飙车，你不上 180 码就是"落后"。问题是，这条路到底通去哪儿？

### 优化建议

- [x] 风格 A：开头用具体画面（表弟吃药）抓人，情绪递进自然。
- [x] 风格 B：数据对比清晰，结尾开放式提问引导讨论。
- [x] 风格 C：两代人故事对比，细节真实（借来的半本书、杀猪）。
- [x] 风格 D：反讽递进到位，结尾自嘲收尾。
- [x] 风格 E：3 句话内完成，适合信息流快速阅读。
