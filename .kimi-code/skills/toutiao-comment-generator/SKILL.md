# 头条评论生成器

> **用途**：你提供一个话题 + 你的原始观点，我帮你完善成适合今日头条评论区的高互动文案。

---

## 一、使用流程

### 你的输入（只需两步）

```
话题：______________
我的观点：______________
目标情绪：愤怒 / 共鸣 / 幽默 / 震惊 / 温暖 / 其他_____
```

**如果你没有明确观点**，我会在理解话题 / 原文后，先推荐 **3-5 个高传播力的观点方向**供你选择，你选一条或自行补充后再生成评论。

### 触发方式

直接输入：

```
/toutiao-comment-generator
```

或自然语言：

```
帮我写条头条评论
话题：#现在高考和几十年前有啥不一样#
我的观点：现在的高考虽然制度更公平了，但孩子们的压力反而更大了
目标情绪：共鸣 + 轻微无奈
```

## 二、生成器工作流

### 步骤 0：读取并深度思考原文（如用户提供文章/链接）

当用户提供了文章链接或文件路径时，先完成对原文的深度思考：

1. **读取原文**：如果是文件路径，直接读取；如果是网页链接，请用户复制粘贴正文或提供截图/标题。
2. **保存临时文件**：将原文保存到 `{源文件目录}/.toutiao-comment-think-temp.md`（若只有文本无目录，则保存到当前工作目录）。
3. **调用追本思考**：运行 `/Users/chouchou/.claude/skills/ljg-think {临时文件路径}`，对原文进行纵向深度钻探，追问：
   - 作者在解决什么问题？
   - 文章核心论点脚下的地面是什么？
   - 有哪些反常识点、矛盾、被忽略的前提？
   - 如果要写评论，可以从哪几层切入？
4. **提炼评论角度**：基于 `ljg-think` 的思考结果，在进入痛点匹配前，先确定 1-3 个最有传播力的评论切入角度。

**注意**：此步骤仅针对用户提供了文章/链接的场景。若用户只提供了话题和观点，直接进入步骤 1。

### 步骤 1：确认观点方向

在读取痛点图谱和拆解观点之前，必须先明确用户想表达的核心观点。

- 如果用户已经提供了清晰的"我的观点"，直接确认并进入步骤 2。
- 如果用户没有提供观点，或观点比较模糊，基于话题 / 步骤 0 的追本思考结果，生成 **3-5 个推荐观点选项**，以清单形式呈现给用户，每条选项包含：
  - 观点一句话
  - 简要说明这个角度为什么容易有高互动
  - 推荐目标情绪
- 用户可以从推荐选项中选择，也可以回复自己的观点。
- 必须等用户明确选定观点后，再继续进入步骤 2。

**示例输出**：

```markdown
根据这个话题 / 原文，我帮你梳理了 4 个适合在评论区发声的角度，你选一个，或者告诉我你想怎么表达：

A. 观点：40+ 发朋友圈不是炫耀，是在对抗生活的麻木
   角度：从"意义感缺失"切入，情绪共鸣强
   推荐情绪：温暖 + 轻微自嘲

B. 观点：中年人不是不爱分享，是没人值得分享
   角度：从"社交圈层缩小"切入，扎心感强
   推荐情绪：共鸣 + 无奈

C. 观点：敢发朋友圈的中年人，终于学会了不解释
   角度：从"自我认可"切入，适合走金句路线
   推荐情绪：温暖 + 坚定

D. 观点：朋友圈是中年的回忆录，不是舞台
   角度：从"记录对抗遗忘"切入，故事感强
   推荐情绪：共鸣 + 感慨

你选哪个？或者告诉我你的版本。
```

### 步骤 2：读取痛点图谱

首先读取本地痛点图谱文件：

```
/Users/chouchou/Documents/Obsidian Vault/九局下半怎么破局/参考资料/40岁中年危机痛点图谱_完整报告.md
```

将用户选定的话题和观点与图谱中的 20 个 40 岁中年危机痛点进行匹配，找出最相关的 1-3 个痛点。

匹配维度：
- 话题领域是否对应（教育、职场、家庭、健康、财务等）
- 观点情绪是否与痛点情绪一致
- 用户目标受众是否属于 40 岁左右中年群体

如果用户提供了文章/链接，在匹配痛点时，要结合步骤 0 的 `ljg-think` 思考结果，判断文章底层刺痛了哪些中年危机痛点。

### 步骤 3（可选）：查询论据库

在生成评论前，可调用 `evidence-query` 检索本地论据库，查看是否有能支撑用户观点的概念、数据、案例或金句。

调用方式：

```bash
python /Users/chouchou/.agents/skills/evidence-query/scripts/evidence_query.py "话题关键词" --top 5
```

检索后判断：
- 如果返回的论据**高度契合**用户观点，可在评论中自然引用或化用。
- 如果返回的论据**关联度一般**或**不适合评论区语境**，直接弃用，不强行加入。
- 论据只是参考选项，不是必须项。

### 步骤 4：观点拆解

将用户选定的原始观点拆分为以下要素：

- **核心立场**：你支持什么、反对什么（示例：反对鸡娃教育）
- **情绪底色**：你写这条评论时是什么情绪（示例：愤怒 + 心疼）
- **具体场景**：这个观点对应什么生活画面（示例：孩子周末排满补习班）
- **反常识点**：有没有跟大众认知不一样的地方（示例：成绩好的孩子反而更压抑）
- **用户痛点**：读评论的人会被什么戳中（示例：自己也正在焦虑的家长）

### 步骤 5：角度选择

根据话题和观点，选择最合适的切入角度：

- **亲历者角度** — "作为一个……的人，我想说……"
- **数据/事实角度** — "很多人不知道，其实……"
- **反讽角度** — "说得真好，但现实是……"
- **共情角度** — "看到这条新闻，第一个想到的是……"
- **追问角度** — "有没有人想过，为什么……"
- **对比角度** — "十年前的……，现在的……"

### 步骤 6：文案生成

根据以上分析，生成 **3-5 条不同风格的评论**：

#### 风格 A：情绪冲击型（最抓眼球）
- 开头：一个画面或场景（不用铺垫）
- 中间：情绪递进（从疑问到愤怒/心疼）
- 结尾：反问或金句收尾

#### 风格 B：理性分析型（适合争议话题）
- 开头：一个数据或事实
- 中间：拆解逻辑，指出被忽略的点
- 结尾：开放式提问，邀请讨论

#### 风格 C：故事共鸣型（最容易获赞）
- 开头：一个具体的人或事
- 中间：细节描写，让读者"看到画面"
- 结尾：情绪总结，引发"我也是"的共鸣

#### 风格 D：反讽调侃型（适合轻松话题）
- 开头：一本正经说反话
- 中间：越说越离谱，读者才反应过来
- 结尾：真相揭晓，带自嘲

#### 风格 E：短平快型（适合信息流快速阅读）
- 一共 2-3 句话
- 第一句：钩子（好奇/愤怒/共鸣）
- 第二句：核心观点
- 第三句：反问或感叹

### 步骤 7：优化检查

每条评论通过以下 checklist：

- [ ] 开头是否能在 3 秒内抓住人（如果第一句话平淡，删掉重写）
- [ ] 是否有具体的画面或细节（抽象概念不如一个具体场景）
- [ ] 情绪是否真实（避免过度煽情，头条用户讨厌"演"）
- [ ] 结尾是否有互动点（反问、提问、邀请补充）
- [ ] 有没有"爹味"（避免说教感，头条用户讨厌被教育）
- [ ] 字数是否在 50-200 字之间（太长没人看完）
- [ ] 是否像真人在说话（读出来通顺，不像 AI 写的）

## 三、痛点匹配与论据参考说明

生成评论前，先完成三件事：

### 1. 观点确认（必须）

用户必须明确一个核心观点后，才能进入后续流程。推荐观点应基于：
- 用户输入的话题
- 步骤 0 的追本思考结果（如有原文/链接）
- 头条评论区最容易引发互动的角度（情绪共鸣、反常识、自我故事、社会观察）

推荐观点的写作要求：
- 每个选项一句话，观点鲜明
- 简要说明这个角度的传播理由
- 给出推荐情绪
- 至少提供 3 个、最多 5 个选项

### 2. 痛点匹配（必须）

与 40 岁中年危机痛点图谱进行匹配。匹配到的痛点应作为评论的"锚点"，帮助确定：

1. **情绪基调**：愤怒、无奈、焦虑、自嘲、温暖等
2. **切入角度**：从亲历者、共情者还是分析者切入
3. **关键词选择**：使用与目标痛点高度相关的词汇
4. **避免踩雷**：不要触碰与目标情绪冲突的表达方式

### 3. 论据参考（可选）

通过 `evidence-query` 检索论据库，查找与话题相关的概念、数据、案例、金句。

使用原则：
- **宁缺毋滥**：只有比用户原始观点更精准、更有冲击力、更适合评论区语境的论据才采用。
- **自然化用**：不要直接搬运学术化表达，要改成评论区"人话"。
- **标注来源**：如果使用了论据库中的素材，在输出中简要标注参考了哪些条目。

如果用户的输入明显不属于中年危机相关话题，仍然执行痛点匹配，但可以在输出中说明"该话题与痛点图谱关联较弱，以下评论基于通用高互动文案逻辑生成"。

## 五、进阶技巧

### 评论区心理学

1. **被顶到前排的评论往往不是最对的，而是最像"人话"的**
2. **带数字的比纯文字更容易被点赞**（"我们班一半人" > "很多人"）
3. **情绪 + 细节 = 真实感**，缺一不可
4. **适当的留白**（不说完）比说完更有互动量
5. **用"我"而不是"你们"** — 头条用户喜欢听个人故事，不喜欢被代表

### 避雷清单

- ❌ 不要用排比句（"既是……也是……更是……"）— 太像官方发言
- ❌ 不要列一二三 — 评论区不是写论文
- ❌ 不要过度引用名人名言 — 显得刻意
- ❌ 不要写"我觉得/我认为" — 直接说观点，头条读者没耐心
- ❌ 不要写超过 300 字 — 除非你的故事真的精彩
